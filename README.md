# TP3-HTML-Y-CSS

Resolución de los 20 ejercicios del TP3 de HTML y CSS, separados en carpetas por bloque y por ejercicio individual.

- BLOQUE-1 (Ejercicios 1 a 7): Estructura HTML básica, etiquetas semánticas, listas, tablas y formularios.
- BLOQUE-2 (Ejercicios 8 a 13): Maquetación, estilos con CSS, Flexbox y Grid Layout.
- BLOQUE-3 (Ejercicios 14 a 20): Variables CSS, diseño responsivo, animaciones y la Landing Page final (*La Secta del Parque*).



Diseño

- **Color favorito:** Uso de una paleta verde consistente (`#345a39` de color principal y fondos pastel suaves) en todos los ejercicios con CSS.
- **Variables CSS:** Aplicadas desde el Ejercicio 14 para mantener coherencia estética en todo el Bloque 3.
- **Responsivo:** Adaptado para que se vea bien tanto en PC como en celulares.
- **Interacciones:** Efectos visuales y carrusel logrados con CSS puro (`scroll-snap`), sin complicarse con JavaScript.
- **Imágenes:** Archivos locales para los servicios y temáticas de cada punto.
